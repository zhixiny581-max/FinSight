# 接口配置说明（展示版 · deploy/show-v2）

本文只讲 Python 展示版（`deploy/show-v2`）的密钥怎么放、放哪里、什么不会上传。旧版与 Node 版的 `.env` 配置见根目录 README。

一句话版本：**密钥写成两个文件中的任意一个，都不会进 Git、不会进上传包；展示机放项目内那份，同学本地部署复制模板填一份就行。**

## 一、两个文件，三种来源

服务启动时按下面的顺序找凭据，找到就停，不再往下找：

| 优先级 | 来源 | 位置 | 谁用 |
| --- | --- | --- | --- |
| 1（最高） | 系统环境变量 | 系统设置 / 启动脚本里 `set` | 服务器部署、临时覆盖 |
| 2 | **项目配置** | `deploy/show-v2/api-config.json` | 展示机、同学本地部署 |
| 3 | 用户配置 | `~/.finsight/config.json`（项目文件夹外） | 多项目共用同一套 key |

- 高优先级覆盖低优先级，但**只覆盖填了的那一项**，没填的项继续往下一层找。
- 没有设置环境变量或配置文件时，服务仍可启动，接口设置页会标「未配置」。
- 环境变量优先级最高，是为了线上服务器能直接注入，不用改文件。

## 二、同学本地部署：三步

1. **生成配置文件**

   双击 `deploy/show-v2/打开配置文件.cmd`，脚本会从模板复制出 `api-config.json` 并用记事本打开。

   也可以手动复制：把 `api-config.example.json` 复制一份，改名为 `api-config.json`。

2. **填写**

   打开后是这样的结构，只填你有的项，没有的留空：

   ```json
   {
     "ifind": "Bearer xxxxxxxx",
     "deepseek": "sk-xxxxxxxxxxxxxxxx",
     "tavily": "",
     "deepseek_base_url": "",
     "deepseek_model": ""
   }
   ```

   注意：值必须放在英文双引号里，左边字段名不要改。留空等于没配，不影响启动。

3. **启动并验证**

   双击 `deploy/show-v2/启动展示站.cmd`。在「接口设置」确认对应服务显示「已配置」，然后手动刷新快讯或打开行情页面验证取数。

## 三、展示机：把密钥跟着项目走

课堂上用的那台机器，建议用**项目配置**这一层，好处是拷走整个项目文件夹就等于把配置带走了，不用在教室重新填一遍。

做法：

1. 在平时准备的电脑上，双击 `打开配置文件.cmd`，把展示用的 key 填进 `api-config.json`
2. 完整拷贝 `FinSight` 文件夹到展示电脑（U 盘或网盘均可）
3. 在展示电脑上双击 `启动展示站.cmd`，在「接口设置」查看状态，再验证快讯和行情

该文件在项目目录内，替换机器时不会丢；同时又不会进 Git、不会进上传包，见下一节。

如果同一台机器上还有别的项目也要用这套 key，再运行一次 `设置密钥.cmd` 写用户配置，两份文件互不影响。

## 四、排查

| 页面提示 | 含义 | 怎么处理 |
| --- | --- | --- |
| 未配置 | 这一项在环境变量、两个文件里都没找到 | 按第二节填进 `api-config.json`，保存后重启服务 |
| 授权无效或已过期（401） | 值读到了，但上游不认 | 确认是**原样粘贴**（别自己再加一层 `Bearer`）、是否已过期、复制时是否带进了空格或换行 |
| 无访问权限（403） | 账号没有该接口权限 | 换有权限的账号，或找提供方开通 |
| 连接超时 | 网络到不了上游 | 检查代理、校园网出口；换个网络试试 |
| 接口返回错误，稍后重试 | 上游临时故障 | 过几分钟再重试对应功能 |

命令行也可以看，不用开浏览器：

```powershell
cd deploy/show-v2
python -c "import config_store,json;print(json.dumps(config_store.status(),ensure_ascii=False,indent=1))"
```

`status()` 可在本机诊断配置来源。网页接口只返回是否配置。

## 五、上传 GitHub 时会发生什么

`api-config.json` 有三重保护，正常操作不会被传上去：

1. `.gitignore` 里有 `**/api-config.json`，`git add .` 会跳过它
2. `tools/prepare-release.cjs` 的禁止规则里显式排除这个文件名，即使有人把它写进白名单也会被拦下并报错
3. 打包脚本会读取本机 `api-config.json` 里的真实值，如果这些值出现在任何待打包文件里，直接停止打包

只有 `api-config.example.json`（空模板）会进仓库和上传包。

所以：

- **不要**把填好的 `api-config.json` 单独发到群里或网盘公开链接
- **不要**在截图、文档、聊天里贴完整 key
- 展示结束后如果用的是公用电脑，双击 `设置密钥.cmd`，对应项输入 `-` 就能清掉用户配置；项目配置文件直接删掉即可

## 六、网页能不能读到我的密钥

网页调用 `/api/health` 读取配置状态。接口只返回各服务的 `configured` 布尔值，不返回密钥、掩码或服务器路径。

这也是为什么**修改密钥必须改文件后重启**，不能像某些后台那样在网页上填：公网部署时页面是公开的，一旦提供写入入口，任何人都能替换你的 key。

## 七、字段速查

| 字段 | 环境变量 | 必填 | 说明 |
| --- | --- | --- | --- |
| `ifind` | `IFIND_MCP_AUTHORIZATION` | 是 | iFinD 授权串，新闻、行情、标的共用 |
| `deepseek` | `DEEPSEEK_API_KEY` | 是 | 新闻摘要、质量审核、智能分析 |
| `tavily` | `TAVILY_API_KEY` | 否 | 补公开网页证据，留空则该工具标为不可用 |
| `deepseek_base_url` | `DEEPSEEK_BASE_URL` | 否 | 用中转服务时填，留空走 `https://api.deepseek.com` |
| `deepseek_model` | `DEEPSEEK_MODEL` | 否 | 留空用项目默认 `deepseek-flash` |

## 八、相关文件

| 文件 | 作用 |
| --- | --- |
| `deploy/show-v2/api-config.example.json` | 空模板，可提交，同学复制它 |
| `deploy/show-v2/api-config.json` | 真实配置，**不提交**，展示机与本地部署用 |
| `deploy/show-v2/config_store.py` | 读取与合并逻辑、掩码输出 |
| `deploy/show-v2/打开配置文件.cmd` | 生成并打开 `api-config.json` |
| `deploy/show-v2/设置密钥.cmd` | 写用户级配置 `~/.finsight/config.json` |
| `deploy/show-v2/app.py` | 启动时注入、`/api/health` 只读状态 |
