# 交付复核记录

复核日期为2026年11月2日。交付目录是FinSight，旧版留在原有目录，新版位于versions/feedback。本记录说明已检查的行为及边界，不表示所有新闻的经济判断均已被独立验证。

## 发现并修复的问题

1. **原分享包遗漏分析模块。** 旧版package.ps1只包含新闻原型文件。保持旧文件不变，新增根目录白名单打包工具，完整包含两个运行版本、空配置模板、测试和说明；排除密钥和本机数据。
2. **补证阶段候选查询状态描述错误。** 在实际公司查询发生前，模型输入一律明确为尚未查询，避免用候选为空反向否定行业查询。
3. **完整结构校验未接入新版编排。** 接回已有结构校验，对无有效路径等无效首稿修复一次，无效补证修订保留上一份有效结果。
4. **prompt示例与收窄范围不一致。** 直接参与方示例收敛为身份与关系，不再暗示已完成公司独立方向研究；缺少事件关联证据的定价示例改为无法判断。
5. **副本来源容易混淆。** 新版状态接口增加版本及实例标识；启动器核对对应目录实例，端口被其他程序占用时拒绝重复启动，不结束其他进程。
6. **启动后关闭终端导致服务退出。** 根目录启动器改为后台运行，独立保存日志和PID；停止时核对PID、完整命令路径与端口。中文路径的进程核对使用UTF-8输出，已验证停止成功。
