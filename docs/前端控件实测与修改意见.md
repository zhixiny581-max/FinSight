# FinSight 前端控件实测与修改意见（2026-11-04）

> 范围：只谈**前端 UI 与交互逻辑**。数据接入（iFinD / DeepSeek 是否配置、示例数据是否真实）不作为判定依据，也不在此列。
> 测试对象：`deploy/show-v2/index.html`（课程展示站实际页面）；同源问题在 `versions/feedback/.../index-core.html` 一并标注。
> 本轮**未改任何业务代码**，只新增了审计脚本。

---

## 一、这次是怎么测的

不是"读代码猜"，而是把页面跑起来、把控件一个个点过去：

1. 启动真实服务 `PORT=8765 python -B deploy/show-v2/app.py`，访问 `http://127.0.0.1:8765/core`（不是 `file://` 本地文件）。
2. 在页面脚本执行**之前**注入钩子，包裹 `EventTarget.prototype.addEventListener`，记录每个元素（含祖先委托）到底有没有绑定 `click`。
3. 对每个候选控件执行：记录状态指纹 → `click()` → 等 650ms → 再记录指纹 → 比对。
4. 判定四类：**真响应** / **有监听但无可见变化**（条件不满足） / **假按钮**（CSS 可点、无监听、无变化） / **纯展示**。

覆盖 4 个屏共 **58 个可交互元素**（同类最多取 2 个样本避免重复），另加 9 项结构性探测（hash、localStorage、快捷键、滚动记忆、aria 等）。

**统计**：真响应 26 · 条件不满足 10 · 假按钮 2 · 纯展示 10 · 表单控件 7 · 外链 3。
判断依据文件：`docs/ui-preview/audit/report.json`、`docs/ui-preview/audit/controls.json`。

> **先撤回一个误判**：我一开始以为「日期筛选坏了」——点日期后列表没变。复核后发现 `bindCalendar()` 逻辑正确，是我点到了禁用格子。真实原因是弹层默认停在**当前月（11 月）**，而示例数据在 9 月，11 月整月 30 天全部 `disabled`（实测 `enabled=0`）。这仍然是前端问题（默认月份定位策略），但**不是**筛选功能失效，详见问题 10。

## 二、总体结论

页面骨架和主链路是**完整可用**的：四屏导航、新闻卡片/热榜→智能分析、收藏、词云表格切换、行情口径切换、产业链放大、公司行→K 线抽屉、日历月份与统计、导入错误提示、390px 响应式，全部正常；无 JavaScript 运行时异常。

问题集中在三类：
- **少数"看起来能点、其实没反应"的控件**（2 个铁证 + 3 个状态不一致）；
- **所有状态都只活在一次会话里**（收藏、主题、筛选、页面位置全丢）；
- **已有信息没有变成可操作入口**（词云、周条、热榜前 5、日历格子）。

## 三、我找到的问题

### A. 假按钮：CSS 说能点，实际没有响应

| 位置 | 现状 | 问题 |
|---|---|---|
| 导入页 Tab「粘贴链接」 | `.tabs button` 有 `cursor:pointer` + hover 样式；实测自身监听 0、祖先监听 0，点击前后 DOM 完全不变 | 全页只有这一个 tab，没有任何切换逻辑，是**装饰性按钮**。用户会以为还有别的方式可切 |
| 导入记录空状态行「还没有导入记录」 | `table.tbl tbody tr{cursor:pointer}` 是全局规则，空状态行也继承；实测该行 `cursor:pointer`、行内按钮 0 个、无监听 | 空状态被渲染成"可点击的数据行"，点它毫无反应。应把光标规则限定到有数据的行 |
| 分析页「开始 AI 分析」 | `#anaRun` 与 `#aiRunInline` 均 `disabled=true`、`cursor:not-allowed`；`title` 为空，无 `aria-disabled`，相邻无说明 | 确实禁用了，但**不告诉用户为什么**。旁边 `aiStatus` 还写着 `http://127.0.0.1:3000` —— 当前站点根本没有这个地址 |
| 导入页「开始打标」 | `disabled=false`、主按钮高亮；但导入记录为 0（只有占位行），点击只把一行 11px 小字改成「当前没有待打标新闻。」 | 按钮可用性与实际可用对象不一致：无待打标项时应禁用并改文案 |
| 开市日历屏的日期格子 | 渲染为 `<button class="cal-d" disabled>`、`cursor:default`、无监听 | 用 `<button disabled>` 表达"只读展示"在语义上说得通，但视觉上**没有任何只读提示**，用户会反复点 |

### B. 做成了装饰，但信息本可以变成操作

| 位置 | 现状 | 问题 |
|---|---|---|
| 标签词云（快讯流右栏） | 20 个 `.cw` 是纯 `<span>`，`cursor:default`、无监听 | 字号已经编码了出现次数，却不能点；想按某标签筛选只能去下拉框里找同一个词 |
| 开市日历·本周（右栏周条） | 7 个 `.c` 格子，`cursor:auto`、无监听 | 能看出哪天开市/有快讯，但点不进去 |
| 信息重要度榜 | 固定渲染 5 条，页面无"查看全部"入口 | 用户不知道总共有多少条高重要度新闻，也没法看第 6 条以后 |
| 智能分析页 | 无"上一条 / 下一条" | 连续读多条必须"返回快讯流 → 再找下一条"，打断阅读节奏 |

### C. 状态与导航：刷新即丢，链接不可分享

| 位置 | 现状 | 问题 |
|---|---|---|
| 收藏 | 存在内存 `state.favorites`；实测 `localStorage` 为空数组 | 刷新页面收藏全部消失 |
| 主题 | `#themeBtn` 只改 `document.documentElement.dataset.theme` | 刷新回浅色，不记忆 |
| 筛选条件 | 日期/星级/标签/排序/仅看收藏都在 `state.filters` 内存里 | 刷新全部丢失 |
| 页面切换 | `showScreen()` 不写 `location.hash`；实测点击导航后 `location.hash === ""`（只在初始化时读一次 hash） | 刷新回到快讯流；**无法分享"我在智能分析页"的链接**；浏览器前进/后退失效 |
| 手动刷新 | `resetLiveFeedFilters()` 先整体重置 `state.filters`，随后 `syncTagOptions()` 又用当前下拉值把 `tag` 改回原值 | 刷新后筛选**部分重置**：标签保留，星级/收藏/排序/日期丢失。实测列表 1 条 → 4 条，而控件显示与实际条件不一致 |
| 滚动位置 | 切屏时执行 `window.scrollTo({top:0})`；实测 feed → analysis → feed 回来 `scrollY=0` | 长列表下每次返回都要重新找位置 |

### D. 跨屏与键盘

| 位置 | 现状 | 问题 |
|---|---|---|
| 顶部搜索框 | 四个屏都有；在智能分析页输入"测试"，页面仍停在 `s-analysis`，无任何提示 | 搜索**只在快讯流生效**，在别的页面输入毫无反馈 |
| 全局键盘 | 只绑定了 Escape 关闭弹层/抽屉；实测按 `/` 后焦点仍停在 `BODY` | 没有 `/` 聚焦搜索、没有 ↑↓ 或 J/K 移动、没有 Enter 打开、没有 F 收藏、没有 T 切主题 |
| 导航项 | 已是 `<button>`，可 Tab 聚焦、可 Enter 触发（上一轮已改） | ✅ 可用；但缺 `aria-current` 标识当前页 |
| 焦点环 | 上一轮已补 `:focus-visible` | ✅ 可用 |

### E. 渲染与一致性

| 位置 | 现状 | 问题 |
|---|---|---|
| 快讯流右栏「下一次调休上班」 | 恒定显示 `undefined（周undefined）` | `MAKEUP_DAYS` 只硬编码到 `2026-10-10`，之后 `filter()[0]` 为 `undefined` 仍直接插值；**跨年后整表失效** |
| 日期筛选弹层 | 默认停在当前月 2026-11，30 天全部 `disabled`（实测 `enabled=0`），而数据在 9 月 | 用户点日期毫无反应，极易误判为功能损坏。应自动定位到"最近有快讯的月份"，或在本月无快讯时明说 |
| 分析页 `aiStatus` | 文案含 `http://127.0.0.1:3000` | 当前站点是 8765 / 线上域名，该地址是旧版 Node 端口，误导用户 |
| 导入页拖拽区 | CSS 里 `.dropzone` 有完整样式（`:hover`、`.drag`、虚线边框），HTML 中**已无该元素** | **死 CSS**，约 5 条规则永不生效；看起来"本来有拖拽上传" |
| 收藏按钮 | 只有 `title="加入收藏"`，无 `aria-pressed` | 已收藏/未收藏对读屏软件不可见 |
| 主题按钮 / 图标按钮 | 只有 `title`，无 `aria-label` | 图标按钮缺稳定可访问名称 |
| 词云「表格」/「仅看收藏」 | 无 `aria-pressed` | 开关状态不可见 |
| 日历统计 | 21 交易日 + 9 休市 = 30 天，与 `days=30` 一致 | ✅ 正常 |
| 导入页「清空」 | 实测输入 `abc测试` 后点击，textarea 变空（`cleared:true`） | ✅ 正常（旧版清单说它没绑定，当前版本已修好） |

## 四、优化清单

按「对使用习惯的价值」排序，全部是纯前端逻辑，不碰接口。

### 批次一：状态记忆与真实感（推荐先做）

| # | 改动 | 说明 | 量 |
|---|---|---|---|
| 1 | 收藏持久化 | `localStorage` 存收藏 id，刷新/重开仍在 | 小 |
| 2 | 主题持久化 | 首次读 `prefers-color-scheme`，用户手动切过后记忆 | 小 |
| 3 | 筛选条件持久化 | 日期、星级、标签、排序、仅看收藏都记住；刷新后与控件状态**同时**恢复 | 小 |
| 4 | 页面写入 hash | 切屏时 `history.replaceState(null,'','#'+id)`，刷新和分享都停在原页；顺带让前进/后退可用 | 小 |
| 5 | 修 5 处假按钮 | ①「粘贴链接」tab 要么删掉 tab 样式、要么补切换逻辑；②空状态行光标规则限定到 `tbody tr[data-id]`；③分析按钮禁用时补 `title`/相邻说明；④「开始打标」无待打标项时禁用并改文案；⑤日历格子明确只读或补提示 | 中 |

## 五、怎么复跑验证

```bash
# 1) 起服务（数据目录放临时目录，不污染仓库）
cd AI智能体设计/FinSight/deploy/show-v2
PORT=8765 DATA_DIR="$TEMP/finsight-runtime-data" python -B app.py

# 2) 控件审计（逐元素点击 + 监听器核查）
cd AI智能体设计/FinSight
node tools/ui-audit.cjs http://127.0.0.1:8765 9226

# 3) 交互回归（44 步主链路）
node tools/ui-smoke.cjs http://127.0.0.1:8765 9224
```

`ui-audit.cjs` 输出 `docs/ui-preview/audit/report.json`，逐元素给出 `cursor / own / up / verdict`。修完后重点看：

- `dead-pointer` 计数应为 **0**（当前 2：粘贴链接 tab、导入空状态行）；
- `listener-no-change` 里的「开始打标」「开始 AI 分析」应变成 `disabled` + 有说明，或点击后有明显反馈；
- 结构性探测中 `hashAfterNav` 不再是空串、`localStorageKeys` 非空、`hasResetButton` 为 true、`slashFocus.after` 指向搜索框。
