# 反馈修订版分析模块

范围是事件与板块的大致方向、经营传导、条件与反向路径，以及iFinD返回的相关公司名单。没有逐家公司财务或业务暴露研究。方向可信度与影响强度分开，均不代表收益概率。

| 文件 | 作用 |
| --- | --- |
| `prompts/feedback.txt` | 当前实际发送给模型的分析规则、JSON示例、claims和tool_requests约定 |
| `feedback-service.js` | 初稿、按需补证、回传修订、结构校验、引用检查、预算与审计 |
| `feedback-normalizer.js` | 字段标准化和结构校验，不自动补齐宏观因果边 |
| `evidence_tools.js` | iFinD新闻、可选Tavily搜索、公开网页读取 |
| `evidence-records.js` | 稳定资料段落ID、来源使用策略、模型实际获得的证据片段 |
| `feedback-market.js` | 上海时区事前截止点、窗口指标、日期对齐与定价约束 |
| `test-feedback.js` | 合成场景的机制回归测试 |

`analysis_service.js` 和 `prompts/impact-analysis.txt` 是用于保留兼容代码、基础回归和对照的文件；当前新版入口调用的是 `feedback-service.js`，实际prompt是 `feedback.txt`。不要把它们当作新版实际调用入口。

主链由 `../news/prototype/server.js` 编排。所有事件/板块补证完成后才查询公司；查询结果挂接时不再调用模型。模型只接收新闻和事前市场背景，不接收最新全A行情。

当前工具最多2轮、6次调用，额外取证累计45秒，模型单次45秒，整个请求240秒；修复调用也共享总预算。iFinD检索和公开网页读取按需执行；Tavily未配置时标为不可用。网页无法读取、没有可靠发布时间或不符合历史时点要求，不会伪装成已取得的事前证据。

结构检查不等于语义全对。引用检查覆盖模型声明的claims，可验证段落是否实际提供、引文是否存在及资料时点，无法替代人对经济含义和新闻真实性的判断。原始输入保持新闻模块提供的材料范围。

配置、启动、回退、双版本隔离与上传步骤见[根目录README](../../../../README.md)。讲解见[分析模块讲解稿](../../../../docs/presentation/分析模块讲解稿.md)。
