## 七、后续调整（同日 · 按产品反馈）

### 7.1 日期翻页不再关闭弹层

- **现象**：在日期弹层里点 `‹ / ›` 翻月，弹层立刻关闭。
- **根因**：翻月会调用 `renderDatePanel()` 重建整个面板，被点击的按钮随即脱离文档；事件继续冒泡到 `document` 上的「点外部关闭」逻辑时，`pop.contains(e.target)` 因为目标已不在 DOM 中而返回 `false`，于是误判为“点了外部”。
- **修复**：翻月按钮的监听里加 `e.stopPropagation()`，阻止事件到达 `document`。
- **验证**：`2026 年 9 月 → 点 › → 2026 年 10 月（弹层保持打开）→ 点 ‹ → 2026 年 9 月`。

### 7.2 删除标签词云

- **范围**：右栏整块「标签词云」卡片移除；同时删除 `TAG_STATS` / `TAG_CAT` / `cloudMode` / `renderCloud()` / `#cloudToggle` 监听 / 初始化调用 / `.cloud` 系列 CSS。
- **注意点**：只删 HTML 不删监听会留下 `null.addEventListener`，导致整段脚本中断——已一并清理。
- **验证**：`#cloudWrap`、`#cloudToggle` 均不存在，样式表内已无 `.cloud` 规则，无 JS 异常。

### 7.3 快讯流改为分页

- **规则**：默认每页 10 条（`const PAGE_SIZE=10`，改这一处即可调整）；列表底部显示「← 上一页 / 第 x / y 页 · 共 n 条（本页 a–b）/ 下一页 →」。
- **联动**：筛选、搜索、排序任一变化自动回到第 1 页；数据刷新导致页数变少时自动收敛到最后一页；总数不超过一页时整条分页栏隐藏。
- **验证**（注入 29 条）：第 1 页 10 条（上一页禁用）→ 第 2 页 10 条 → 第 3 页 9 条（下一页禁用）；切到 5 星筛选后回到第 1 页并隐藏分页栏。

> **本地看不到分页是正常的**：内置示例数据只有 6 条，不足 10 条时分页栏会隐藏。接真实数据超过 10 条才会出现。

## 八、日历联动、2027 年扩展与右栏热股榜（同日 · 第三轮调整）

### 8.1 周条显示年月日并与开市日历联动

- **原状**：右栏「开市日历·本周」只显示日期数字（1–31），星期靠上方表头；点击无反应，与「工具 → 开市日历」完全割裂。
- **改动**：每格改为两行 `<button>`，上行「周X」、下行「月/日」（如 `周三` / `11/04`）；整格可点，点击调用 `openCalendarAt(ds)` —— 设置 `state.cal` 到该月、记录 `calHighlight`、切到日历屏并渲染。
- **高亮**：月历格子在原 `.sel` 基础上补了 `.cal-d.m-open.sel` 等组合选择器，因为 `.m-open` 的底色原本会覆盖 `.sel`。
- **验证**：点本周第 4 格（11/04）→ 屏切到 `s-calendar`、标题 `2026 年 11 月`、`#calGrid .cal-d.sel` 命中。

### 8.2 日历延伸到 2027 年

- **数据来源**：2027 年放假方案已于 2026 年 11 月初公布（新华社、人民日报等转载）。据此补入 7 个假期区间：元旦 1/1–1/3、春节 2/5–2/12、清明 4/3–4/5、劳动 4/30–5/4、端午 6/9、中秋 9/15、国庆 10/1–10/7。
- **边界处理（重要）**：2027 年**具体调休上班日尚未公布**（公开报道只写“劳动节调休 1 天、国庆调休 2 天”）。因此：
  - `MAKEUP_DAYS` 不补 2027 的未知日期，新增 `MAKEUP_COVERAGE = {2026:true, 2027:false}`；
  - 周条脚注在该年度未覆盖时显示「2027 年调休上班日待交易所公布；周末与法定节假日仍休市。」，不再输出 `undefined`；
  - 「休市安排」表中 2027 年春节/劳动节/国庆的调休列显示「待交易所公布」，而非误标为“无”。
- **开市判断不受影响**：调休上班日都落在周末，交易所本就休市，所以“是否开市”只依赖周末 + 法定节假日，2027 年的判断是准确的（实测 `2027-02-08` → 春节休市、`2027-02-15` → 开市、`2027-05-03` → 劳动节休市、`2027-06-09` → 端午休市）。

- **表格**：标题改为「2026–2027 年休市安排」，共 14 行，来源说明补充 2027 年口径。

### 8.3 右栏新增「新闻提及标的」

## 九、右栏改为东方财富 A 股人气榜（同日 · 第四轮）

### 9.1 需求与取舍

- 删除「信息重要度榜」（以及此前临时加的「新闻提及标的」）。
- 右栏只保留**东方财富 A 股人气榜 Top 20**，显示更新时间，并提供「⟳ 更新」按钮重新抓取。

### 9.2 数据来源（已实测可用）

| 用途 | 接口 |
|---|---|
| 榜单 | `POST https://emappdata.eastmoney.com/stockrank/getAllCurrentList`（即 `guba.eastmoney.com/rank/` 页面所用） |
| 补名称/行情 | `GET https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&secids=...&fields=f12,f13,f14,f2,f3` |

榜单接口只返回 `sc`（如 `SH688825`）、`rk`（排名）、`rc`、`hisRc`，**不含股票名称与价格**，因此第二步用行情接口按代码批量补齐 `f14` 名称、`f2` 最新价、`f3` 涨跌幅。两次请求合计约 1–2 秒。

**必须走后端的原因**：两个接口都不返回 `Access-Control-Allow-Origin`，浏览器从本站域名直接 `fetch` 会被 CORS 拦截；榜单接口还要求 `POST` + JSON 头。因此新增 `deploy/show-v2/popularity.py` 做服务端代理，前端只调用同源 `/api/rank`。

### 9.3 实现

- **后端**：`popularity.py` 独立模块（只用标准库），`base.py` 注册 `GET /api/rank?limit=20`（上限 50）。返回 `{ok, source, sourceUrl, updatedAt, updatedAtText, limit, items[], note}`，`items` 每项含 `rank / code / market / name / price / changePct`。
- **错误分级**：`RANK_TIMEOUT` / `RANK_UNREACHABLE` / `RANK_HTTP` / `RANK_PARSE` / `RANK_REJECTED` / `RANK_EMPTY`，每种都有对应的中文提示，**绝不返回假数据**。
- **不缓存到磁盘**，不写任何用户数据；行情补齐失败时榜单仍显示，只是价格列为 `—`。
- **前端**：右栏卡片「人气榜 · 东方财富」+ 副行「更新于 YYYY-MM-DD HH:mm:ss · 来源 东方财富（非交易建议）」+ 20 行（排名 / 名称 / 代码 / 最新价 / 涨跌幅）。涨红跌绿按 A 股习惯；前 3 名排名序号加粗变色。
- **更新按钮**：点击期间禁用并显示「⟳ 更新中…」，请求完成后恢复；重新请求并刷新时间戳。
- **点击个股**：站内已有该代码的新闻 → 跳转到对应智能分析；没有 → 把名称填入搜索框并切到快讯流过滤。

## 十、本地试验人气榜的操作方式

### 10.1 为什么不能直接双击 HTML

人气榜接口没有 CORS 响应头，浏览器从 `file://` 页面直接请求会被拦截；榜单接口还要求 `POST` + JSON 头。**必须由本地服务做代理**，所以要用下面的启动脚本，而不是双击 `index.html`。

### 10.2 两个双击即用的脚本（`deploy/show-v2/` 目录）

| 文件 | 作用 | 期望输出 |
|---|---|---|
| **`测试人气榜.cmd`** | 只验证网络与接口，不开网页 | 命令行打印前 20 名（排名/名称/代码/最新价/涨跌幅）与更新时间 |
| **`启动展示站.cmd`** | 启动网站并自动打开浏览器 | 浏览器打开 `http://127.0.0.1:8765/core`，右栏显示人气榜 |

- 换端口：在当前目录执行 `启动展示站.cmd 8767`
- 绿色窗口**不要关**，关掉即停止服务
- 两者都只依赖 Python 标准库，**不需要 pip install 任何东西**

### 10.3 辅助文件

| 文件 | 说明 |
|---|---|
| `run_local.py` | 启动器主体。批处理里处理中文路径与嵌套引号极易出错，所以把“定端口 / 延时开浏览器 / 起服务”都放到 Python |

### 10.4 批处理编码的坑（已处理）

`.cmd` 文件**必须是 GBK 编码**，若存成 UTF-8，cmd.exe 会把中文行读成乱码并报“不是内部或外部命令”。本次两个 `.cmd` 最终改为**纯 ASCII 内容**（提示信息全部放在 Python 里打印），从根本上避开编码问题。

## 十一、人气榜卡片的三处调整（同日）

### 11.1 去掉内部滚动条

- **原状**：`.ranklist` 设了 `max-height:376px; overflow-y:auto`，20 条只露出约 7 条，其余要在卡片内部滚动，视觉上像嵌了一个独立小窗口。
- **改动**：删除 `max-height` 与 `overflow-y`，改为 `display:flex;flex-direction:column`，**20 条全部展开**，整张卡片随页面一起滚动，与新闻流同一套滚动。
- **验证**：`maxHeight = none`、`overflowY = visible`、`scrollHeight === clientHeight`（959px），无内部滚动。

### 11.2 取消点击行联动

- **原状**：`.rankrow` 是可点击的 `<button>`，点击会跳到站内相关新闻的分析页，或把股票名塞进搜索框。
- **改动**：渲染改为 `<div>`，删除 `click` 监听与 `data-rank-code` / `data-rank-name`，同时移除 `cursor:pointer` 与 `:hover` 底色——避免"看起来能点但没反应"。
- **验证**：`tag = DIV`、`cursor = auto`、无 data 属性；点击后 `screen` 保持不变（仍是 `s-feed`）。

### 11.3 附上东方财富官方网址

卡片底部新增一行链接：

```
东方财富个股人气榜 ↗   → https://guba.eastmoney.com/rank/
```

`target="_blank"` + `rel="noopener"`，新标签页打开；样式为强调色文字 + 上分隔线，`hover` 出现下划线。

### 11.4 与新闻分页的对齐实测

| 场景 | 左栏底部 | 榜单卡底部 | 差值 |
|---|---|---|---|
| 示例数据 6 条（分页隐藏） | 1363 | 1644 | 榜单比左栏长 281px |
| 满页 10 条（分页显示） | 分页底 2176 | 1644 | 榜单比左栏**短 532px** |

**结论**：去掉滚动条后榜单高度固定为 20 行（约 1081px），而新闻卡片高度随标题/摘要长度浮动，因此**两者无法精确对齐**。当前状态是"各自自然展开、随页面统一滚动"，不再有内部小滚动条。

如果要让右侧视觉上填满，可选方案：①把抓取条数从 20 提到 30（东方财富接口支持 `pageSize`，但会偏离"人气榜 Top 20"的常规口径）；②保持 20 条，接受右栏短于左栏。当前实现是方案 ②。
