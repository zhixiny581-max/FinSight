# iFinD MCP 接入与实测记录

## 接入方式

本模块直接从后端连接 iFinD 股票 MCP，使用用户提供配置里的 `hexin-ifind-ds-stock-mcp`。
不依赖 Codex 安装此 MCP，不需要把 MCP 的 Token 转换成传统 iFinD HTTP API Token。
不调用配置中其他基金、港股、企业或新闻服务。

服务地址：`https://api-mcp.51ifind.com:8643/ds-mcp-servers/hexin-ifind-ds-stock-mcp`。
请求沿用配置的 `Authorization` 值，不擅自添加 Bearer 前缀。
协议实现支持服务实际协商的 `2024-11-05` 版本，完成 initialize / initialized / tools/call，兼容 JSON 和 SSE 响应。
如服务分配 Session ID，则后续请求携带并在结束后尝试释放。
协议参考：[MCP Streamable HTTP 官方说明](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports)。

## 只读工具与映射

| MCP 工具 | 用途 | 核验过的返回格式 |
| --- | --- | --- |
| `get_stock_performance` | 前复权日频 OHLC 与成交量 | `content[].text` 内 JSON → `data` 内 JSON → `answer` Markdown 表格及 `indicators_params` |
| `stock_highfreq_quotes` | 最新行情快照 | 同样的两层 JSON → `tables`，包含代码、简称、time、最新价、涨跌幅 |

历史查询必须传入明确起止日期，不能只写“最近 60 天”。
工具使用自然语言选取指标，因此返回列顺序可能变化；解析按字段名定位。
实测长区间存在 100 行结果截断，所以后端每批最多查询 28 个日历日，向前取数直到满足根数或达到查询边界。
日 K 数量默认 60，允许 1–120。最长回看范围为 `n * 2 + 30` 个日历日，且受已配置日历年份限制。

## 数据校验

- 四个价格的指标参数必须分别明确写明“前复权”，否则 HTTP 502，不能混用不复权数据。
- 每个批次明确要求以查询时最新日期为复权基准；并非历史时点不变的回测价格快照。
- 成交量元数据必须明确是股或手，支持数值中的万/亿；统一输出为股（1 手 = 100 股）。
- `chg` 已是百分数，例如 `1.85` 代表 `1.85%`，不再次乘 100。
- 最新价格 `px` 与前复权历史收盘 `c` 是不同时间和用途的数据，不强制缩放 K 线与最新价相等。
- 股票代码、日期范围、高低价关系、有限数值、重复日期均校验。
- 实测休市日可能返回“只有填充收盘价，开高低量为空”的占位行；这类行跳过，绝不生成 K 线。
- 交易日为空或成交量为零的行不填补；返回缺失日期和不足根数标记。不能仅凭缺失断言停牌。
- 原始响应格式或指标含义改变时明确报错，不用随机数据或旧示例冒充。

## 本机配置

把完整 MCP 配置文件保存在项目目录之外，启动前设置文件路径：

```powershell
$env:IFIND_MCP_CONFIG = 'C:\你自己的目录\ifind-mcp.json'
.\.venv\Scripts\python.exe -m uvicorn modules.market.app:app --host 127.0.0.1 --port 8000
```

路径指向 JSON 配置内容；扩展名 `.json` 或 `.txt` 均可。
也可使用 `modules/market/start.ps1 -IfindConfigPath '你的配置文件路径'`。
不要把真实 MCP 配置复制到仓库。示例环境文件没有真实授权值，也不会自动加载。

`/api/market/health` 的 `quoteStatus=configured` 仅说明本机配置可读，不能代替在线权限检查。
HTTP 401/403 映射为 `IFIND_UNAUTHORIZED`；限流、超时、缺数据、格式异常分别返回明确错误。
默认直连 HTTPS，不使用机器上可能失效的代理；确需代理时设置 `IFIND_TRUST_ENV=true`。

## 缓存与边界

行情快照缓存 15 秒，日 K 缓存 300 秒，仅存本进程内，重启清空；最多 128 个键。
缓存命中保留原 `fetchedAt`。`asOf`/`quoteAsOf` 来自供应商数据时间，绝不用请求时间冒充。
非交易时段快照可能为最近一笔数据，消费者应展示或检查时间。
并发缓存未命中会在本进程排队，避免对账号发起请求突发；这是本机/小团队版本，不是高并发生产服务。
